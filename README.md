## PhpHyphenation

Расстановка мягких переносов в русском, английском и немецком тексте. Алгоритм Ляна–Кнута, словари из TeX.

Каждый git-тег — релиз под одну версию PHP. Код переносов один и тот же, у релиза своё ограничение PHP.

## Установка

```bash
composer require mifesta/hyphenation-php:~8.5.0
```

| Релиз | PHP |
|---|---|
| `~7.4.0` | 7.4 |
| `~8.0.0` | 8.0 |
| `~8.1.0` | 8.1 |
| `~8.2.0` | 8.2 |
| `~8.3.0` | 8.3 |
| `~8.4.0` | 8.4 |
| `~8.5.0` | 8.5 |

Нужны расширения `iconv` и `mbstring`. Пакет `mifesta/filesystem-php` не используется.

## Использование

```php
use Hyphenation\Hyphenation;

$hy = new Hyphenation('ru_RU');
echo $hy->hyphenate('Автоматическая расстановка переносов в узкой колонке.', 'UTF-8');
```

Языки: `ru_RU`, `en_US`, `en_GB`, `de-1996`. Неизвестный код языка выбрасывает `InvalidArgumentException`.

По умолчанию вставляется символ U+00AD. Второй аргумент — кодировка текста (`UTF-8`, `CP1251` и другие имена `iconv`). Третий аргумент — свой маркер в UTF-8, например `&shy;`. Четвёртый, если передать `false`, отключает пропуск слов внутри `<...>`. Текст между тегами переносится, значения атрибутов — нет.

Слово, перед которым стоит `\`, не переносится. Слово из одних заглавных пропускается. Внутренние заглавные тоже, пока не включён `$hy->proceed_uppercase = true`.

Минимальные поля слева и справа заданы в `src/conf`. `set_limits()` может только увеличить их.

Первый вызов собирает словарь и записывает его в `src/completed`. Если каталог пакета закрыт для записи, кэш кладётся во временный каталог системы.
